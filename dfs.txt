📚Поиск в глубину (Depth-First Search или DFS) – это один из фундаментальных алгоритмов для обхода и анализа графов. Он используется для нахождения всех вершин, которые достижимы из заданной стартовой вершины в ориентированном или неориентированном графе.

Алгоритм начинает с заданной стартовой вершины и последовательно исследует все вершины, связанные с текущей вершиной, путем спуска вглубь графа до тех пор, пока возможно, и возвращается обратно, если все вершины уже были исследованы или текущая вершина больше не имеет непосещенных соседей.

Основные идеи и шаги алгоритма DFS:

Посетите текущую вершину (начиная с стартовой вершины) и пометьте ее как посещенную.
Рекурсивно посетите всех непосещенных соседей текущей вершины (если они есть) и повторите шаг 1.
Повторяйте шаги 1 и 2, пока все вершины не будут посещены.
Примечание: DFS может быть реализован как рекурсивная функция или с использованием стека для хранения вершин, которые нужно посетить.

Рекурсивная реализация алгоритма DFS на C++:

```cpp
#include <iostream>
#include <vector>
#include <unordered_set>

class Graph {
private:
    int numVertices;
    std::vector<std::unordered_set<int>> adjList;

public:
    Graph(int vertices) : numVertices(vertices), adjList(vertices) {}

    void addEdge(int source, int destination) {
        adjList[source].insert(destination);
        // Если граф неориентированный, добавьте следующую строку:
        // adjList[destination].insert(source);
    }

    void DFSUtil(int node, std::vector<bool>& visited) {
        visited[node] = true;
        std::cout << node << " ";

        for (int neighbor : adjList[node]) {
            if (!visited[neighbor]) {
                DFSUtil(neighbor, visited);
            }
        }
    }

    void DFS(int startNode) {
        std::vector<bool> visited(numVertices, false);
        DFSUtil(startNode, visited);
    }
};

int main() {
    int numVertices = 7;
    Graph graph(numVertices);

    graph.addEdge(0, 1);
    graph.addEdge(0, 2);
    graph.addEdge(1, 3);
    graph.addEdge(1, 4);
    graph.addEdge(2, 5);
    graph.addEdge(2, 6);

    int startNode = 0;
    std::cout << "DFS traversal starting from node " << startNode << ": ";
    graph.DFS(startNode);

    return 0;
}
```

Обратите внимание, что в примере использован класс Graph для представления графа с помощью списка смежности. Вы можете добавить ребра и изменить стартовую вершину, чтобы протестировать DFS для различных графов и стартовых вершин.

Нерекурсивная реализация алгоритма DFS на C++ с использованием стека:

```cpp
#include <iostream>
#include <vector>
#include <unordered_set>
#include <stack>

class Graph {
private:
    int numVertices;
    std::vector<std::unordered_set<int>> adjList;

public:
    Graph(int vertices) : numVertices(vertices), adjList(vertices) {}

    void addEdge(int source, int destination) {
        adjList[source].insert(destination);
        // Если граф неориентированный, добавьте следующую строку:
        // adjList[destination].insert(source);
    }

    void DFS(int startNode) {
        std::vector<bool> visited(numVertices, false);
        std::stack<int> stack;

        stack.push(startNode);
        visited[startNode] = true;

        while (!stack.empty()) {
            int currentNode = stack.top();
            stack.pop();
            std::cout << currentNode << " ";

            for (int neighbor : adjList[currentNode]) {
                if (!visited[neighbor]) {
                    stack.push(neighbor);
                    visited[neighbor] = true;
                }
            }
        }
    }
};

int main() {
    int numVertices = 7;
    Graph graph(numVertices);

    graph.addEdge(0, 1);
    graph.addEdge(0, 2);
    graph.addEdge(1, 3);
    graph.addEdge(1, 4);
    graph.addEdge(2, 5);
    graph.addEdge(2, 6);

    int startNode = 0;
    std::cout << "DFS traversal starting from node " << startNode << ": ";
    graph.DFS(startNode);

    return 0;
}
```

В этой нерекурсивной реализации DFS используется стек для хранения вершин, которые нужно посетить. Алгоритм повторяет следующие шаги:

Поместить стартовую вершину в стек и отметить ее как посещенную.
Извлечь вершину из вершины стека, напечатать ее и добавить всех непосещенных соседей в стек.
Повторить шаг 2 до тех пор, пока стек не станет пустым.
Этот подход позволяет обойти граф в глубину без использования рекурсии, что особенно полезно для больших графов, где рекурсивный вызов может привести к переполнению стека.
