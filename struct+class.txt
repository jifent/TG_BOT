Составные типы данных в C++ позволяют объединять несколько значений разных типов в одну структуру или контейнер. Это позволяет создавать более сложные структуры данных, которые могут содержать различные типы информации и группировать их вместе для более удобной организации данных.

Ниже приведены некоторые примеры составных типов данных в C++:

Структуры (struct) позволяют создавать пользовательские типы данных, объединяя несколько переменных различных типов в одну единицу. Каждая переменная в структуре называется членом структуры.

```cpp
struct Person {
    std::string name;
    int age;
    char gender;
};

int main() {
    Person person1;
    person1.name = "John";
    person1.age = 30;
    person1.gender = 'M';

    std::cout << "Name: " << person1.name << ", Age: " << person1.age << ", Gender: " << person1.gender << std::endl;

    return 0;
}
```

Классы (class) – это более продвинутая версия структур, которая также позволяет объединить данные и методы (функции) для работы с этими данными. Они являются основой объектно-ориентированного программирования.

```cpp
class Rectangle {
public:
    int length;
    int width;

    int calculateArea() {
        return length * width;
    }
};

int main() {
    Rectangle rect;
    rect.length = 5;
    rect.width = 3;

    std::cout << "Area: " << rect.calculateArea() << std::endl;

    return 0;
}
```

Составные типы данных позволяют улучшить структуру кода, обеспечивая логическую группировку данных и обеспечивая удобный доступ к ним.
