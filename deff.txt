Получение длины строки:

<pre><code class="language-cpp">
std::string str = "Hello, world!";
int length = str.length(); // 13
</code></pre>

Получение подстроки:

<pre><code class="language-cpp">
std::string str = "Hello, world!";
std::string subStr = str.substr(0, 5); // "Hello"
</code></pre>

Поиск подстроки:

<pre><code class="language-cpp">
std::string str = "Hello, world!";
size_t pos = str.find("world"); // 7 (индекс начала подстроки)
</code></pre>

Замена подстроки:

<pre><code class="language-cpp">
#include &lt;string&gt;
std::string str = "Hello, world!";
str.replace(7, 5, "everyone"); // "Hello, everyone!"
</code></pre>

Удаление символов из строки:

<pre><code class="language-cpp">
#include &lt;string&gt;
std::string str = "Hello, world!";
str.erase(5, 7); // "Hello!"
</code></pre>

Разделение строки на подстроки:

<pre><code class="language-cpp">
#include &lt;string&gt;
#include &lt;vector&gt;
#include &lt;sstream&gt;
std::string str = "one two three four";
std::vector&lt;std::string&gt; words;
std::stringstream ss(str);
std::string word;
while (ss &gt;&gt; word) {
    words.push_back(word);
}
</code></pre>

Преобразование строки в числовой тип:

<pre><code class="language-cpp">
std::string str = "42";
int num = std::stoi(str); // 42
</code></pre>

Преобразование числового типа в строку:

<pre><code class="language-cpp">
int num = 42;
std::string str = std::to_string(num); // "42"
</code></pre>
