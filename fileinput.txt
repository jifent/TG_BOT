📚В C++, для чтения из файла, вы можете использовать потоки (streams) из стандартной библиотеки <fstream>. Для чтения данных из файла, вам понадобятся следующие шаги:

Включить заголовочный файл <fstream>.

Открыть файл с помощью объекта ifstream (input file stream).

Прочитать данные из файла, используя методы >> или getline().

Закрыть файл после окончания чтения.

Вот пример кода для чтения чисел из файла и вывода их на экран (поэлементно, разделитель – пробел):

```cpp
#include <iostream>
#include <fstream>

int main() {
    std::ifstream inputFile("example.txt"); // Открытие файла для чтения

    if (!inputFile.is_open()) {
        std::cerr << "Не удалось открыть файл." << std::endl;
        return 1;
    }

    int number;
    while (inputFile >> number) { // Чтение чисел из файла
        std::cout << number << " "; // Вывод числа на экран
    }

    inputFile.close(); // Закрытие файла

    return 0;
}
```
