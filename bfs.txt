📚Поиск в ширину (Breadth-First Search или BFS) – это еще один основной алгоритм для обхода и анализа графов. В отличие от поиска в глубину (DFS), который исследует вершины как можно глубже перед тем, как вернуться обратно, BFS исследует все ближайшие вершины, прежде чем переходить к следующему уровню.

Алгоритм начинает с заданной стартовой вершины и исследует все ее соседей на первом уровне, затем переходит к исследованию соседей этих соседей на следующем уровне и так далее. Он использует очередь для хранения вершин, которые должны быть исследованы на текущем уровне.

Основные идеи и шаги алгоритма BFS:

Поместите стартовую вершину в очередь и пометьте ее как посещенную.
Пока очередь не пуста, извлекайте вершину из начала очереди и исследуйте ее соседей.
Если сосед еще не был посещен, поместите его в конец очереди и пометьте как посещенный.
Повторяйте шаги 2 и 3, пока очередь не станет пустой.
Примечание: BFS находит кратчайшие пути от стартовой вершины ко всем другим вершинам в невзвешенном графе.

BFS также находит применение в задачах, связанных с поиском кратчайшего пути, связностью графа, нахождением минимального остовного дерева и т.д. Он может быть полезен в различных сценариях, где важно исследовать ближайшие соседи перед движением на более удаленные.

Реализация алгоритма поиска в ширину (BFS) на C++:

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <unordered_set>

class Graph {
private:
    int numVertices;
    std::vector<std::unordered_set<int>> adjList;

public:
    Graph(int vertices) : numVertices(vertices), adjList(vertices) {}

    void addEdge(int source, int destination) {
        adjList[source].insert(destination);
        // Если граф неориентированный, добавьте следующую строку:
        // adjList[destination].insert(source);
    }

    void BFS(int startNode) {
        std::vector<bool> visited(numVertices, false);
        std::queue<int> queue;

        queue.push(startNode);
        visited[startNode] = true;

        while (!queue.empty()) {
            int currentNode = queue.front();
            queue.pop();
            std::cout << currentNode << " ";

            for (int neighbor : adjList[currentNode]) {
                if (!visited[neighbor]) {
                    queue.push(neighbor);
                    visited[neighbor] = true;
                }
            }
        }
    }
};

int main() {
    int numVertices = 7;
    Graph graph(numVertices);

    graph.addEdge(0, 1);
    graph.addEdge(0, 2);
    graph.addEdge(1, 3);
    graph.addEdge(1, 4);
    graph.addEdge(2, 5);
    graph.addEdge(2, 6);

    int startNode = 0;
    std::cout << "BFS traversal starting from node " << startNode << ": ";
    graph.BFS(startNode);

    return 0;
}
```

В этой реализации BFS используется очередь для хранения вершин, которые нужно исследовать. Алгоритм повторяет следующие шаги:

Помещаем стартовую вершину в очередь и помечаем ее как посещенную.
Извлекаем вершину из начала очереди, выводим ее на экран и добавляем всех непосещенных соседей в очередь.
Повторяем шаг 2 до тех пор, пока очередь не станет пустой.
Вы можете изменить стартовую вершину и добавить новые ребра, чтобы протестировать BFS для различных графов и стартовых вершин.
