📚Бинарный поиск – это эффективный алгоритм поиска элемента в отсортированной коллекции (массиве) путем многократного деления коллекции на половины и исключения половины элементов на каждом шаге, пока не будет найден искомый элемент или не будет определено, что такого элемента в коллекции нет.

Для того чтобы применить бинарный поиск, коллекция должна быть предварительно отсортирована по возрастанию или убыванию. Алгоритм работает следующим образом:

Шаги бинарного поиска:

Задаем начальный индекс left и конечный индекс right коллекции.
Вычисляем средний индекс mid как среднее значение между left и right.
Сравниваем элемент с индексом mid с искомым элементом:
Если элемент с индексом mid равен искомому элементу, поиск завершается, и мы возвращаем индекс mid.
Если элемент с индексом mid больше искомого элемента, то искомый элемент находится слева от mid, и мы обновляем значение right на mid - 1.
Если элемент с индексом mid меньше искомого элемента, то искомый элемент находится справа от mid, и мы обновляем значение left на mid + 1.
Повторяем шаги 2-3 до тех пор, пока left не станет больше right, тогда поиск завершается, и мы возвращаем -1, чтобы указать, что элемент не найден.
Бинарный поиск выполняется за время O(log n), где n - количество элементов в коллекции. Это делает его значительно более эффективным по сравнению с линейным поиском, особенно для больших коллекций.

Пример бинарного поиска в отсортированном массиве (нерекурсивная реализация):

```cpp
#include <iostream>

int binarySearch(int arr[], int left, int right, int key) {
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] == key) {
            return mid; // Искомый элемент найден, возвращаем его индекс
        } else if (arr[mid] < key) {
            left = mid + 1; // Искомый элемент находится справа от mid
        } else {
            right = mid - 1; // Искомый элемент находится слева от mid
        }
    }
    return -1; // Искомый элемент не найден, возвращаем -1
}

int main() {
    int arr[] = {1, 2, 3, 5, 6, 7, 9};
    int size = sizeof(arr) / sizeof(arr[0]);
    int key = 6;

    int result = binarySearch(arr, 0, size - 1, key);
    if (result != -1) {
        std::cout << "Искомый элемент " << key << " найден по индексу " << result << std::endl;
    } else {
        std::cout << "Искомый элемент " << key << " не найден." << std::endl;
    }

    return 0;
}
```

В этом примере функция binarySearch выполняет бинарный поиск в отсортированном массиве arr от индекса left до right и возвращает индекс элемента key, если он найден. Если элемент не найден, возвращается -1.

Пример бинарного поиска в отсортированном массиве (рекурсивная реализация):

```cpp
#include <iostream>

int binarySearchRecursive(int arr[], int left, int right, int key) {
    if (left <= right) {
        int mid = left + (right - left) / 2;

        if (arr[mid] == key) {
            return mid; // Искомый элемент найден, возвращаем его индекс
        } else if (arr[mid] < key) {
            return binarySearchRecursive(arr, mid + 1, right, key); // Искомый элемент находится справа от mid
        } else {
            return binarySearchRecursive(arr, left, mid - 1, key); // Искомый элемент находится слева от mid
        }
    }

    return -1; // Искомый элемент не найден, возвращаем -1
}

int main() {
    int arr[] = {1, 2, 3, 5, 6, 7, 9};
    int size = sizeof(arr) / sizeof(arr[0]);
    int key = 6;

    int result = binarySearchRecursive(arr, 0, size - 1, key);
    if (result != -1) {
        std::cout << "Искомый элемент " << key << " найден по индексу " << result << std::endl;
    } else {
        std::cout << "Искомый элемент " << key << " не найден." << std::endl;
    }

    return 0;
}
```

В этой рекурсивной реализации, функция binarySearchRecursive вызывает сама себя для левой или правой половины массива в зависимости от значения key, которое нужно найти. Каждый рекурсивный вызов сокращает диапазон поиска в два раза, что позволяет быстро находить элемент в отсортированном массиве.

Обратите внимание, что в рекурсивной реализации важно задать базовый случай для выхода из рекурсии. В данной реализации базовый случай - это когда left становится больше right, что означает, что элемент не найден, и функция возвращает -1.
