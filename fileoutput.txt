Для записи в файл в C++, вы можете использовать потоки (streams) из стандартной библиотеки <fstream>. Для записи данных в файл, выполните следующие шаги:

Включите заголовочный файл <fstream>.

Откройте файл с помощью объекта ofstream (output file stream) с опцией std::ios::out (открытие на запись).

Запишите данные в файл с помощью метода << для основных типов данных или метода write() для записи бинарных данных.

Закройте файл после окончания записи.

Вот пример кода для записи данных в файл:

```cpp
#include <iostream>
#include <fstream>
#include <string>

int main() {
    std::ofstream outputFile;
    outputFile.open("example.txt", std::ios::out); // Открытие файла для записи

    if (!outputFile.is_open()) {
        std::cerr << "Не удалось открыть файл." << std::endl;
        return 1;
    }

    // Запись данных в файл
    outputFile << "Пример записи в файл." << std::endl;
    outputFile << "Число: " << 42 << std::endl;
    outputFile << "Плавающее число: " << 3.14 << std::endl;
    outputFile << "Строка: " << "Hello, World!" << std::endl;

    outputFile.close(); // Закрытие файла

    return 0;
}
```
